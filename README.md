# Marwane Oufrid – PhD Research Portfolio

A responsive, dependency-free static portfolio prototype.

## Preview
Open `index.html` in a browser. Alternatively serve locally using:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Edit before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your email address.
2. Replace `https://github.com/` in `index.html` with your profile URL.
3. Add the CV as `files/Marwane_Oufrid_CV.pdf` and update placeholder wording in `cv.html`.
4. Replace schematic project art with actual CAD figures, simulations, and project photos if desired.
5. Verify the accuracy of every project description and add your actual contributions, results, dates, and references.
6. Do not publish confidential or unpublished results without permission.

## Deploy to GitHub Pages
Create a public GitHub repository named `<username>.github.io`, upload the contents of this folder to its root, then open Settings → Pages and deploy from the main branch root. The site will normally be available at `https://<username>.github.io/`.

The site uses no external dependencies; this may improve reliability across different networks, though access from any location should be tested.
